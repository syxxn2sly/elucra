# CLAIRITY Expo app

## Project info

This is the local Expo + React Native app for CLAIRITY.

**Platform**: Native iOS & Android app, exportable to web
**Framework**: Expo Router + React Native

## Local development

Use your preferred code editor and run the app from the `expo/` folder.

```bash
# 1) Install dependencies
bun install

# 2) Start the Expo development server
bun run start

# 3) Start the web preview
bun run start-web
```

For iOS Simulator or Android emulator support, use the standard Expo tooling from the same folder.

## What technologies are used for this project?

- React Native
- Expo
- Expo Router
- TypeScript
- React Query
- Lucide React Native
